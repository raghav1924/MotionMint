# BENCHO_UI_RESEARCH.md — Phase 2.13 Reference Audit

*Audited: 2026-11-25 via headless Google Chrome (`https://bencho.dev/`, `https://bencho.dev/about`, `https://bencho.dev/sounds`, `https://bencho.dev/blocks/huddle`) and public technical references.*

## 1. Browser-Verified Observations

| Area | Observed Pattern on `bencho.dev` | MotionMint Adaptation Decision |
|---|---|---|
| **1. Main Navigation** | Single-row header (`Blocks`, `Sounds`, `Finds`, `Bench`, `Pricing`, `⌘K` search, `Sound off`, `Dark` toggle, CTA). | Preserve MotionMint's Phase 2.12 editorial hairline header (`Components`, `Themes`, `Flow`, `Docs`, `⌘K`, `Light/Dark/System`, `Explore`). Do not clone Bencho's header or sponsor links. |
| **2. Discovery Gallery (`/`)** | Horizontal gesture filter pills (`Hover`, `Press`, `Drag`, `Slide`, `Swipe`, `Type`, `Select`, `Loading`) directly above a multi-column live interactive card grid. | Upgrade `/components` into an interactive laboratory with `"Explore interactions."`, verified counts, `All / New / Free / Pro` tabs, search, category select, and multi-select/single-select gesture pills (`hover`, `drag`, `press`, `swipe`, `type`, `select`, `scroll`, `loading`, `focus`, `drop`, `hold`, `keyboard`). |
| **3. Component Preview Cards** | Spacious rounded preview cards containing live interactive widgets (not screenshots), minimal footer with title and action trigger. | Upgrade `ComponentPreviewCard` with `IntersectionObserver`-gated mounting/animation, interaction-appropriate hover/drag/press hints, verified interaction badges, and varied bento spans on `/components`. |
| **4. Detail Experience (`/blocks/huddle`)** | Large left stage with top-left `Preview | Code` segmented toggle, bottom-right quick controls (Play/Replay, Save, Link), and a clean right-hand contextual property inspector (`Fill`, `Stroke`, `Volume`) + primary workbench CTA (`Add to bench`). | Upgrade MotionMint Component Studio (`/components/[slug]`) with a contextual right-hand live property inspector driven by actual component props, `Preview | Code | Compare` stage tabs, interaction hints derived from component capabilities, and Replay/Reset/Sound/Reduced-Motion controls. |
| **5. Live Property Controls** | Component-specific dropdowns, toggles, sliders, and text inputs that update the live preview immediately. | Build a typed per-component live prop schema & state binding for MotionMint components (`RippleButton`, `PhysicalKnob`, `SwipeCardDeck`, `ThinkingLoader`, `DatePicker`, etc.) plus clean generic prop controls where applicable — never fake controls. |
| **6. Gesture Taxonomy** | Components tagged by human interaction mechanics (`Hover`, `Press`, `Drag`, `Slide`, `Swipe`, `Type`, `Select`, `Loading`). | Extend `CatalogItem` in `lib/catalog.ts` with typed `InteractionType[]`, `livePreview`, `adjustable`, `comparisonSupported`, `soundSupported`, and `motionSupported` fields. |
| **7. Code & Source Inspection** | `Preview | Code` toggle in the stage header keeps installation/source clean and out of the way of interaction. | Retain MotionMint's `ComponentDocs`, CLI/Prompt dock, and source viewer accessible cleanly alongside/below the stage without cluttering the live canvas. |
| **8. Sound Demonstrations (`/sounds`)** | Dedicated `/sounds` route with category filter pills (`Actions`, `Feedback`, `Navigation`, `Notifications`, `Selection`, `Movement`, `Progress`, `System`) and tactile circular gradient pads that play Web Audio synthesized cues on click. | Upgrade `/sounds` with category grouping (`UI Feedback`, `Status Feedback`, `Transitions`), tactile playable cue pads, Play/Stop, preset, volume, global Sound ON/OFF (off by default, no autoplay), optional haptics demo, and `useSound()` snippet. |
| **9. Finds / Inspiration** | Separate `/finds` route curating external designer micro-interactions. | Out of scope for MotionMint; MotionMint's curated exhibition lives cleanly on `/` (`Made to move.`). |
| **10. Bench Side-by-Side** | Separate `/bench` infinite canvas for comparing blocks. | **No standalone `/bench`, `/playground`, or `/canvas` route.** Embed side-by-side **Comparison Workbench** directly inside Component Studio (`/components/[slug]`) and Theme Studio (`/themes`) using isolated `<MotionMintTheme>` scopes. |
| **11. Responsive Layout** | Multi-column desktop cards collapsing cleanly to single-column mobile with drawer navigation. | Maintain `0px` horizontal overflow across `1440×900`, `1280×800`, `768×1024`, and `390×844` with responsive inspector stacking. |
| **12. Hover, Drag & Press** | Micro-interactions respond directly to pointer movement, drag physics, and press without auto-playing all cards at once. | Gate continuous animations with `IntersectionObserver` + `prefers-reduced-motion`; keep drag/press/type interactions responsive on demand. |

## 2. Guardrails Confirmed
- **No Bencho code, CSS, logo, or layout cloning.**
- **No standalone `/bench`, `/playground`, or `/canvas` routes** (`InfinityCanvas` remains a registry component at `/components/infinity-canvas`).
- **Global site appearance** stays strictly `Light / Dark / System` (`--ws-*` tokens); **29 component themes × 2 modes (58 variants)** remain strictly isolated inside `<MotionMintTheme>` (`--mm-*` tokens).

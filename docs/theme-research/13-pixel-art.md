# Pixel Art — Design Research

- **Researched:** 2026-11-25
- **References:** https://dribbble.com/search/pixel-art-ui, https://www.pinterest.com/

## Observed Design Principles
0px crisp pixel-accurate geometry, stepped 2px borders, retro 8-bit/16-bit palettes, and monospace block typography.

## Light Variant Specification
Retro cream `#F4F0D8` CRT paper, `#FFFFFF` dialog box, `#1B1B1B` ink, `#E11D48` / `#2563EB` 16-bit accents, `3px 3px 0 #1B1B1B` stepped shadow.

## Dark Variant Specification
Midnight `#101018` arcade screen, `#1B1B28` dialog box, `#F4F0D8` pixel ink, `#4ADE80` / `#FACC15` 8-bit phosphor accents, `3px 3px 0 #000000`.

## Typography
JetBrains Mono / pixel-crisp monospace, uppercase labels.

## Colour
Restricted retro game palette with sharp contrast.

## Geometry
0px crisp corners everywhere, 2px solid stepped borders.

## Surface & Texture
Hard stepped pixel shadows; zero blur.

## Motion & Interaction
80ms–100ms stepped linear transitions.

## Translation to React Components
Buttons snap with stepped pixel shadows; inputs look like retro RPG dialogue boxes.

## What to Avoid
Smooth rounded pills or Gaussian blurs.

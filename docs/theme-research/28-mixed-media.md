# Mixed Media — Design Research

- **Researched:** 2026-11-25
- **References:** https://dribbble.com/search/mixed-media-ui, https://www.awwwards.com/

## Observed Design Principles
Combining crisp vector UI, ASCII/mono telemetry, collage tags, and layered contrasting materials.

## Light Variant Specification
Studio desk `#F4F4EF` canvas, `#FFFFFF` vector card, `#18181B` ink, `#2563EB` cobalt + `#F59E0B` amber collage accents.

## Dark Variant Specification
Darkroom studio `#111216` canvas, `#1A1C22` vector card, `#F4F4F5` ink, `#60A5FA` cobalt + `#FBBF24` amber accents.

## Typography
Serif + sans + monospace intentional contrast.

## Colour
Studio neutral base with primary ink/cobalt/amber accents.

## Geometry
6px–14px varied layering, 1.5px mixed borders.

## Surface & Texture
Subtle grid + collage depth.

## Motion & Interaction
190ms crisp layered spring.

## Translation to React Components
Components blend mono badges, vector icons, and tactile borders cleanly.

## What to Avoid
Monotonous single-font single-border uniformity.
